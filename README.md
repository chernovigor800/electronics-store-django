**'Интернет-магазин электроники'**

Описание:
---------
   Интернет-магазин на Python с использованием фреймворка Django.
   Многопользовательская платформа для просмотра и покупки товаров
   с корзиной, заказами, категориями, тегами, отзывами и распродажами.
   Использовано хранение информации в сессиях Django для неавторизованных
   пользователей и всех остальных данных в базе данных SQLite. Фронтенд 
   подключен как приложение в `settings.py`.

Основной функционал:
--------------------
    - Регистрация и аутентификация пользователей
    - Просмотр категорий и товаров
    - Добавление товаров в корзину (для анонимных и авторизованных 
        пользователей)
    - Оформление заказов с сохранением истории
    - Система отзывов и рейтинга товаров
    - Система распродаж и цен
    - Профиль пользователя с аватаром и контактными данными
    - Админ‑панель для управления товарами, категориями, заказами, 
        пользователями и т.д.

База данных SQLite со следующими моделями:
------------------------------------------    
    - auth.User — пользователи
    - accounts.ProfileUser — профили пользователей (имя, фамилия, 
        телефон, email, аватар)
    - products.Category — категории товаров
    - products.Product — товары (название, цена, количество, описание, 
        рейтинг и т.д.)
    - products.ProductImage — изображения товаров
    - products.Tag — теги товаров
    - products.Specification — характеристики товаров
    - basket.Basket / basket.BasketItem — корзина и её позиции
    - orders.Order  — заказы пользователей
    - reviews.Review — отзывы пользователей о товарах

Запуск приложения:
------------------
1. Создаем новый проект `python_django_diploma` в Pycharm

2. Копируем содержимое одноименного репозитория GitLab в папку 
   нашего нового проекта

3. Создаем новое виртуальное окружение: `python -m venv .venv`

4. Устанавливаем зависимости из файла requirements.txt: 
   `pip istall -r requirements.txt`

5. Устанавливаем фронтенд-приложение из архива: 
   `pip install diploma-frontend-0.6.tar.gz`

6. Переходим в директорию проекта: `cd diploma_backend/backend/`

7. Выполняем миграции БД: `python manage.py migrate`

8. Запускаем сервер: `python manage.py runserver`

9. Переходим в браузере на стартовую страницу: http://127.0.0.1:8000/

10. Для захода в админ-панель Django и на сайт можно использовать 
    данные суперпользователя из файла: `ADMIN_LOGIN_INFO.md`

11. Для загрузки пользователей в базу данных можно использовать 
    фикстуру из приложения accounts: 
    `python manage.py loaddata accounts/fixtures/users_to_upload.json`
    
    Для загрузки продуктов в базу данных можно использовать 
    фикстуру из приложения products:
    `python manage.py loaddata products/fixtures/products_to_upload.json`
